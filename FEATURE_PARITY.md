# Сверка функций с оригиналом

Сверено с README оригинального проекта: https://github.com/rdavydov/Twitch-Channel-Points-Miner-v2

## Уже есть в Rust-порте

- Device-code вход Twitch и сохранение сессии.
- Добавление каналов, подписки с порядком загрузки, чёрный список.
- Одновременный запуск нескольких аккаунтов; общая аналитика хранит ряды с меткой аккаунта.
- Общие настройки CLI/GUI в одном JSON-конфиге; старый одноаккаунтный конфиг по-прежнему загружается.
- Настройки канала: прогнозы, рейды, Drops, Moments, watch-streak, цели сообщества и режим IRC.
- Ставки: Smart, Most Voted, High Odds, Percentage, Smart Money, выбор сторон 1–8, минимальная и максимальная ставка, доля баланса, stealth, фильтр и режим задержки.
- Приоритеты каналов с изменением порядка.
- Аналитика: JSON-история и HTTP-панель.
- Telegram, Discord, POST webhook и Gotify.
- GUI запускает CLI и показывает его журнал, включая код первого входа.

## Ещё нужно для полного соответствия

- Полные настройки логирования оригинала: уровни отдельно для консоли и файла, ротация файлов, часовой пояс, форматирование и палитра.
- Фильтрация уведомлений по событиям; поддержка Matrix и Pushover; выбор метода GET/POST для webhook.
- Проверить приоритет `SUBSCRIBED`: сейчас он не сортирует каналы по уровню подписки.
- Проверить расчёт коэффициентов/фильтров и задержек ставок на реальных событиях Twitch.
- Аналитические графики, аннотации событий и выбор периода.
- Сверить полный набор событий и финальный отчёт сессии.

Этот список — рабочая сверка, не гарантия полной эквивалентности внутренней реализации Python-проекта.
